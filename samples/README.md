# Synthetische Beispielunterlagen

Alle Dateien in diesem Ordner sind fiktiv und ausschließlich für Demonstration und Tests vorgesehen. Sie stellen keine echte Ausschreibung dar, enthalten keine echte Vergabestelle und dürfen nicht als Angebotsgrundlage verwendet werden.

## Enthaltenes Testszenario

Eine fiktive Vergabe der „Vergabestelle Musterstadt – Demonstration“ umfasst zwei Lose:

- Los 1: Unterhaltsreinigung eines fiktiven Verwaltungsgebäudes im Raum Hannover.
- Los 2: Bewachungs-/Schließdienst, der im Demo-Unternehmensprofil ausdrücklich ausgeschlossen ist.

Das Szenario enthält eine Angebotsfrist, einen Besichtigungstermin, erforderliche Nachweise, eine fehlende Referenzliste und mehrere kalkulierbare Positionen. Es dient dazu, Quellenbelege, Go-/No-Go, Checkliste und Kalkulation nachvollziehbar zu testen.
